# Cabañas Desierto Atacama — Landing & Reservas

Landing page de turismo con sistema de reservas para cabañas en el desierto de Atacama.

## Descripción

Landing page responsive con diseño visual inspirado en el desierto, sistema de reservas completo con validaciones, base de datos en Supabase y confirmación vía WhatsApp y email.

## Stack

- Next.js 16 + React 19 + TypeScript
- Tailwind CSS v4
- Framer Motion (animaciones)
- Supabase (PostgreSQL)
- Nodemailer (emails transaccionales)
- WhatsApp API
- Desplegado en Vercel

## Funcionalidades

- 🏜️ Diseño visual temático con animaciones fluidas
- 📅 Sistema de reservas con selección de cabaña y fechas
- 💾 Persistencia en PostgreSQL vía Supabase
- 📧 Emails de confirmación automáticos con Nodemailer
- 💬 Redirección a WhatsApp con mensaje personalizado
